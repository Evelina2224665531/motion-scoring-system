# 2026-10-28 电脑端姿态模型开发报告

## 目标和范围

依据《动作打分系统初步方案》，验证 YOLOv8n-pose 在 Windows 电脑上的单图和摄像头姿态推理，为后续八法五步拳动作识别和 RK3566 部署建立基线。当前工作仅覆盖人体关键点检测及骨架显示，尚未实现动作分类、评分或板端部署。

## 完成情况

1. 选用 Rockchip RKNN Model Zoo 提供的配套 YOLOv8n-pose ONNX 模型和后处理，使用 ONNX Runtime 在电脑 CPU 上推理。模型输入为 1×3×640×640，输出含人体检测和 17 个关键点。
2. 建立单图推理脚本 `.pose-demo/infer_onnx.py`，支持指定输入和输出路径，在图片上绘制人体框和高置信度骨架。官方示例图片检测到 3 人；项目侧面示例检测到 2 人，其中一人部分入镜。
3. 建立 `.pose-demo/camera_pose.py`，支持摄像头编号、采集后端、画面尺寸和置信度配置，实时显示骨架并将画面录制为 AVI/MJPEG；支持定时停止并防止覆盖现有录像。
4. 通过 `.pose-demo/camera_probe.py` 检查 Windows 摄像头。在可访问设备的环境中，XiaoMi WebCam 的编号 0 可通过 DirectShow 和 Media Foundation 读取画面；编号 1～4 未打开。受限执行环境曾无法访问设备，不能据此判定设备故障。
5. 实际录制约 10.5 秒，保存 96 帧。视频可重新读取，但按固定 15 FPS 编码，播放约 6.4 秒，尚不能作为精确时序分析依据。

## 本机环境与复现

本机实际使用 `D:\python\python.exe`（Python 3.13.5）、OpenCV 4.12.0、NumPy 2.2.6 和 ONNX Runtime 1.31.1。新增依赖放在 `.pose-deps`，OpenCV 来自现有环境；这不是完整隔离的虚拟环境。创建虚拟环境时 `ensurepip` 失败，原因尚未查明。首次安装依赖时 NumPy 2.5.4 超出当前 OpenCV 声明的 `<2.3` 范围，后调整为 2.2.6。

模型权重和数据不随仓库提交。将 [Rockchip 配套 ONNX 模型](https://ftrg.zbox.filez.com/v2/delivery/data/95f00b0fc900458ba134f8b180b3f7a1/examples/yolov8_pose/yolov8n-pose.onnx)保存为 `.pose-demo/yolov8n-pose.onnx`；本次文件 SHA-256 为 `308495EBE4416B40ADF376485252A7B8BA7933A169368B31E74E0F977DED8663`。`.pose-demo/official_yolov8_pose.py` 来自 [Rockchip 官方示例](https://github.com/airockchip/rknn_model_zoo/tree/main/examples/yolov8_pose)，脚本和模型应作为配套版本使用；本次未记录源码提交号，后续需固定并核对许可。

在已有上述环境和模型文件的电脑上：

```powershell
cd D:\Git\motion-scoring-system
$env:PYTHONPATH = ".pose-deps"
D:\python\python.exe .pose-demo\infer_onnx.py --image "D:\照片\动作.jpg" --output ".pose-demo\result.jpg"
D:\python\python.exe .pose-demo\camera_pose.py --camera 0 --duration 10 --output ".pose-demo\practice.avi"
```

摄像头预览按 Q 或 Esc 结束；已有输出文件不会覆盖。`--fps` 设置视频播放帧率，不保证等于实际采集和处理帧率。

## 限制与下一步

- 骨架质量未进行人工标注或独立测试；单帧和摄像头演示不能证明动作识别、计数或评分准确。
- 仅有二维 COCO 17 点，不包含手指、脚尖和脚跟；侧身、遮挡、画面边缘和转身需要重点测试。
- 优先修复录像的真实时序，保存每帧采集时间戳、关键点和置信度，再基于代表动作视频检查关节漂移、漏检、阶段判断和延迟。
- 建立可复现的独立 Python 环境，固定依赖、模型和官方源码版本；之后验证 RK3566 工具链及量化误差。
- 本地原始照片、录像、测试输出、模型和依赖目录未纳入 Git，避免提交个人影像和大文件。
